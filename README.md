# AI-Powered Diagnosis System

A machine learning project exploring the use of predictive models for health-related data analysis. The repository contains Jupyter notebooks for multiple disease prediction tasks and a Python application.

## Overview

The project includes the following prediction modules:

- **Heart Disease Prediction**
- **Lung Cancer Prediction**
- **Parkinson's Disease Detection**
- **Thyroid Disease Prediction**

## Tech Stack

- Python
- Machine Learning
- Jupyter Notebook
- Pandas and NumPy (if used)
- Scikit-learn (if used)


## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/vaiish01/AI-Powered-Diagnosis-System.git
   ```

2. Open the project folder in VS Code or Jupyter Notebook.

3. Install the dependencies required by the notebooks and application.

4. Review the notebooks and run the cells after configuring the required datasets and dependencies.
